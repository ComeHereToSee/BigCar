# BigCar 游戏设计文档（GDD）

## 1. 定位

**一句话**：开真实车型，用车撞车，在碰撞中取胜。

* 不是竞速：没有赛道、没有圈数、没有终点线；速度只是撞击的“弹药”。
* 不是驾驶模拟：没有风景路线和收费站；驾驶手感为碰撞服务——好上手、可预期、撞得响。
* 只有近战：所有改装和装备都通过 **车身接触** 生效，**没有任何远程武器**（数据层强制：装备必须 `contactOnly: true`，
  禁止 `range` / `projectile` / `ammo` 字段，CI 的数据校验会拦截违规内容）。

核心循环：

```
选车/改装 → 进入竞技场 → 找角度、蓄速、撞击 → 结算伤害/得分 → 击毁对手 → 获得金币与经验
      ↑                                                                 ↓
      └──────────── 升级零件 / 购买装备与新车 / 解锁关卡与赛季奖励 ←───────┘
```

## 2. 碰撞系统（游戏核心）

### 2.1 物理

* 每台车是一个刚体（Chaos），按真实车型的 **质量、尺寸、重心高度、功率、扭矩、极速、刹车减速度、转向角** 建模；
* 自研射线悬挂 + 轮胎摩擦椭圆模型：抓地有极限、会甩尾、会侧翻，但有防翻正与复位，保证对抗节奏；
* 物理子步进（高频率求解），高速对撞不会穿模；
* 装备（推土铲、楔形铲、撞角……）是 **真实的碰撞体**，焊接在车身上：楔形铲能物理意义上把对手铲起来。

### 2.2 碰撞判定

每一次接触都由服务器结算（防作弊），先判断“谁在撞谁”（朝向接触点的速度分量），再按接触部位和相对朝向分类：

| 类型 | 判定 | 效果 | 基础分 |
|---|---|---|---|
| 正面对撞 Head-on | 双方车头相对、都在向对方加速 | 双方都受重伤，重车/强化车头占优 | 250 |
| T 字侧撞 T-bone | 车头垂直撞上对方侧面 | 侧面伤害加成 + 横向推力，极易致翻 | 400 |
| 侧刮 Side-swipe | 车头斜向擦过对方侧面 | 中等伤害，扰乱对方行驶 | 120 |
| 追尾 Rear-end | 车头撞上对方车尾 | 后部伤害（发动机后置车型要小心） | 120 |
| PIT 甩尾 | 撞对方后侧角并带横向速度 | 额外偏航扭矩，让对手原地打转 | 300 |
| 铲飞 Launch | 车头从底部/斜面撞入（楔形铲加成） | 把对手抛向空中，落地二次伤害 | 500 |
| 碾压 Crush | 从上方落到对方车顶 | 车顶重创 | 600 |
| 擦碰 Glance | 低能量、角度很小的接触 | 少量伤害，不计分 | 0 |

### 2.3 伤害模型

* 伤害 = 碰撞相对动能（按双方质量换算的有效质量 × 相对速度²）÷ 能量系数，低于 2.5 m/s 的接触不造成伤害；
* 车身分为 **前、后、左、右、顶、底 6 个分区 + 发动机 + 4 个车轮**，各自有耐久和护甲：
  分区耐久 = 车型韧性 × (400 + 0.35 × 质量kg) × 分区权重；护甲（0–75%）抵消对应分区伤害；
* 撞击方用车头吃伤害，被撞方承受主要伤害；冲撞力（ramPower）、侧撞加成、自伤减免等由升级和装备调整；
* 车身 **实时程序化变形**（按接触点和能量凹陷），某个分区被打穿时对应的车身板件脱落飞出，车轮会被撞掉（影响操控），
  发动机低于 25% 起火持续掉血，整体完整度低于 12% 即被 **击毁**（爆炸、残骸留在场上成为障碍物）；
* 冲出擂台、掉进坑里等算作 **推出（Ring-out）**，最后接触你的对手获得击毁。

### 2.4 计分与连击

* 撞击得分 = 基础分 × 严重程度系数（0.7–1.3）× 连击倍率（短时间内连续有效撞击递增）；
* 击毁 1000、助攻 350、推出 800、复仇 300、连续击毁额外 500×N、滞空每秒 40、破坏场景物件 50；
* 击毁判定：最近一次造成伤害的对手；推出判定：最近一次接触的对手；同队永远不得分（但有伤害）。

## 3. 车辆

* **89 台车 / 44 个品牌原型**，覆盖：家用轿车、掀背、紧凑车、旅行车、MPV/厢式车、SUV、越野车、皮卡、
  肌肉车、轿跑、性能跑车、豪华车、超跑、Hypercar、重型卡车；
* **5 个档次（Tier 1–5）**：从入门家用车到百万级超跑；档次决定基础战力（CR）和匹配分段；
* 每台车有 6 项展示属性：速度、加速、操控、重量、耐久、冲撞（由物理参数实时计算，不是手填）；
* 不同车型的打法差异来自真实物理：重型皮卡/SUV 擅长正面硬碰和推出，低趴超跑擅长高速 T-bone 和铲飞，轻车灵活但脆。

### 真实车型与授权

所有车辆都按真实车型的公开参数建模（`vehicles.json` 的 `reference` 字段记录对应真实车型）。
汽车品牌名、车型名、外观设计和标志受商标与外观专利保护，商业发行前必须逐一取得厂商授权。因此：

* 默认显示 **虚构品牌名**（`brands.json` 中 `licensed: false`，例如原型为丰田的“星野”、原型为日产的“龙神”），车身外观为程序化通用造型；
* 取得某个品牌的授权后，把该品牌改为 `licensed: true` 即显示真实品牌与车型名，再按下文替换正式车模即可；
* 该开关同时用于商城展示、联机名称与存档，无需改代码。

## 4. 改装、升级与装备

### 4.1 性能升级（9 类 × 5 级）

| 类别 | 主要影响 |
|---|---|
| 发动机 | 功率、扭矩、极速 |
| 变速箱 | 换挡时间、加速 |
| 悬挂 | 稳定性、防侧倾、落地 |
| 轮胎 | 抓地、轮胎耐久 |
| 刹车 | 制动力 |
| 底盘结构 | 整车耐久、发动机耐久 |
| 装甲 | 各分区护甲 |
| 配重 | 质量（更重更能撞但更慢）、重心 |
| 氮气 | 氮气容量、推力、回复 |

价格 = 基础价 × 档次系数（高档车升级更贵）。每级升级 +10 战力（CR）。

### 4.2 装备（47 件，全部近战）

| 槽位 | 例子 | 作用 |
|---|---|---|
| 前部 | 重型撞杆、钢制楔形铲、排障器、推土铲、撞角 | 冲撞力、铲飞、正面护甲 |
| 后部 | 加固后杠、尾部尖刺 | 后部护甲、反追尾伤害 |
| 侧面 | 侧裙装甲、侧面撞刃 | 侧面护甲、侧刮伤害 |
| 车顶 | 防滚架、车顶装甲 | 防碾压、翻车保护 |
| 车轮 | 尖刺轮毂、实心胎 | 撞击时破坏对方轮胎、防爆 |
| 核心 | 加固车架、自修复系统 | 耐久、持续修复 |
| 技能 | 氮气爆发、液压跳跃、蓄力冲撞、防御姿态、紧急维修、电击保险杠 | 主动技能（E 键），有冷却 |

装备有车型类别限制（例如推土铲只能装在卡车/皮卡/SUV 上），每件装备都有可见的碰撞几何体。

## 6. 单人战役与探索

* **8 个章节、64 个关卡**：锈谷新人 → 黑水暗流 → 沙海毒蝎 → 白狼山口 → 不夜城 → 钢铁炼狱 → 霓虹高地 → 冠军之夜；
  主角从废车场的地下撞车赛一路打到“撞击之王”冠军之夜，每章一个 BOSS（锈铁之王、黑色货车、毒蝎、孤狼、鬼影、铁塔、夜莺……）；
* 每关有主目标（获胜 / 击毁数 / 限时 / 无伤 / 推出 / 占点 / 生存 / 破坏 / 收集 / 击败 BOSS）和 **3 个星级挑战**；
  章节与关卡按星数和前置关卡解锁；部分关卡强制使用剧情指定的车和配装；
* 关卡前后有剧情对话（角色：老秦、火花、小鱼、白先生、解说雷子）；
* 每章有一张 **开放枢纽地图**，自由驾驶探索：隐藏收集品、秘密地点（跳台、隐藏区域）；
* **探索度** = 40% 收集品 + 30% 星数 + 20% 关卡完成 + 10% 秘密，按章节和总体显示；
* 首通给全额奖励，重玩给 25% 金币 / 50% 经验，新获得的星额外奖励。

AI 难度：新手 / 常规 / 老手 / 精英 / BOSS，另有性格：莽夫（只会正面撞）、诡术师（专打侧面和 PIT）、
猎手（盯残血目标）、求生者（躲避、等机会）。AI 会预判、绕后、蓄速、使用技能、避开擂台边缘。

## 7. 联机

* **快速匹配**：自由混战 / 团队模式，可按地区匹配，人数不足时用 AI 补位；
* **天梯排位**：1v1、2v2、3v3 团队淘汰；Glicko-2 积分，青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 撞击之王，每段 3 个小段；
  按积分相近匹配（等待越久可接受的积分差越大），优先同地区，超时后放宽；排行榜按赛季统计；
* **组队**：最多 3 人，6 位邀请码，队长开匹配，全队一起进入同一队伍（最多 3v3）；
* **自定义 / 局域网**：直接输入地址加入或自己开房；
* **专用服务器**：服务器权威（碰撞、伤害、得分都在服务器计算），客户端只发送操作；结果由服务器上报后端统一结算，防作弊；
* 断线：对局中断开视为离开，排位按负场计算；服务器异常中止的对局不计分并让玩家重新排队。

## 8. 成长与经济

* 玩家等级 1–100，每级奖励金币、装备、外观；
* 对局奖励 = 参与奖 + 得分折算，胜利 ×1.5，排位 ×1.25，单局有上限；
* **双货币**：金币（游戏内获得，买车/升级/装备）、点券（充值获得，买礼包/外观/通行证，也可买金币礼包）；
* **商城**：精选礼包、车辆、装备、外观（涂装、轮毂、撞击火花、喇叭、旗帜、称号）、每日特惠（每天 6 个随机折扣，10%–50%）、点券包（多档位，大额有赠送）；
* **赛季通行证**：免费轨道 + 高级轨道，按经验升级领取奖励；
* 已拥有的车/装备再次获得时自动折算为 50% 价值的金币，不会浪费；
* 所有购买在服务器端校验与扣款，带幂等，避免重复扣费；单机进度离线可玩，登录后同步。

* 预设：低 / 中 / 高 / 史诗 / 电影；

  全局光照方式（Lumen / SSGI / 关）、反射方式（Lumen / SSR / 关）、硬件光线追踪、虚拟阴影贴图、接触阴影、体积雾、环境光遮蔽、
  运动模糊、泛光、镜头光晕、景深、色差、胶片颗粒、暗角、各向异性过滤、锐化、碎片细节、车身变形细节；
* 超分与帧生成：TSR / TAA / FXAA / DLSS（含帧生成、Reflex）/ FSR 4 / FSR 3.1 / XeSS，详见 [UPSCALERS.md](UPSCALERS.md)；

* 音频：主音量 / 音乐 / 音效 / 引擎 / 界面；语言：简体中文 / English。

## 10. 美术资源替换

当前所有视觉与声音都是程序化生成的占位（保证工程零二进制依赖、可在 CI 中完整编译测试）：

| 现在 | 替换为正式资源 |
|---|---|
| 程序化可变形车身（按真实尺寸生成） | 在 `vehicles.json` 给车型增加模型路径，`ABCVehiclePawn` 使用骨骼网格 + 变形目标/顶点偏移，伤害接口不变 |
| 数据生成的竞技场（基础几何体） | 在 UE 编辑器中搭建关卡，放置 `ABCArenaBuilder` 读取出生点/道具/收集品数据，或直接摆放同类 Actor |
| 合成器实时生成的发动机/轮胎/撞击音效 | 替换 `UBCSynthComponents` 为 MetaSounds 资源，按同样的转速/滑移/冲击参数驱动 |
| Slate 程序化 UI | 可逐页改为 UMG，`ABCPlayerController` 的界面切换接口不变 |

所有玩法逻辑都在引擎无关的 `CrashCore` 中，替换美术不会影响碰撞、伤害、经济等任何规则。
